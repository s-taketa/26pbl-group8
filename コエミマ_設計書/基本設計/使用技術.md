## 1. ハードウェア構成

| 構成項目 | 選定リソース | 役割 |
|---|---|---|
| 本体 | Raspberry Pi 5 | エッジ実行ユニット。撮影・音声入出力・ウェイクワード検知 |
| ストレージ | MicroSDカード（32GB〜） | OS・モデル・ログ格納 |
| 電源 | ラズパイ5専用電源（5V/5A） | 高負荷時の電圧降下防止 |
| 目（カメラ） | Raspberry Pi カメラモジュール（NoIR） | 映像配信・画像認識のソース |
| 耳・口 | USBマイク ＋ USBスピーカー | ハンズフリー対話。開発時はUSBヘッドセットも可 |
| 起動ボタン | 物理プッシュボタン（GPIO18） | 音声が拾えない場面の確実な起動手段 |
| サーバー | 専用PC（Ubuntu 24.04 LTS） | AI解析・音声合成・DB・管理画面を集約 |

---

## 2. ソフトウェアスタック

### 2.1 エッジ（Raspberry Pi 5）
| 分類 | 採用技術 | 役割 |
|---|---|---|
| OS | Raspberry Pi OS（64-bit） | エッジ用OS |
| 言語 | Python 3.11 | エッジ制御全般 |
| 音声認識(STT) | **Vosk 0.3.45** | 完全オフラインのウェイクワード監視＋コマンド聞き取り |
| 映像処理 | OpenCV / Picamera2 | 撮影・NoIR青み補正（R-B入れ替え）・JPEG化・MJPEG配信 |
| 音声入力 | PyAudio | マイク入力 |
| GPIO | gpiozero（lgpio） | 物理ボタン（GPIO18）制御 |
| Webフレームワーク | Flask | サーバー命令待受（/command）・映像配信（/video） |
| 音声再生 | aplay（ALSA） | サーバーから受け取ったWAVの再生 |

### 2.2 サーバー（Ubuntu）
| 分類 | 採用技術 | 役割 |
|---|---|---|
| OS | Ubuntu 24.04 LTS | 常時起動サーバー基盤 |
| 言語 | Python 3.11 | サーバー処理全般 |
| Webフレームワーク | **Flask** | 管理API・画面提供・エッジ連携 |
| AI | Google Gemini API（**2.5 Flash**） | 画像＋テキストのマルチモーダル解析 |
| 音声合成(TTS) | **VOICEVOX エンジン** | 回答テキストの音声化（文単位ストリーミング） |
| データベース | **MySQL 8.0** | 認識ログ・通知履歴・設定の中央管理 |
| ORM/ドライバ | SQLAlchemy 2.0 / PyMySQL | DBアクセス |
| 認証 | Werkzeug security | パスワードハッシュ（generate/check_password_hash） |
| メール送信 | smtplib（Gmail SMTP） | 認証コード送信 |
| 実行基盤 | Docker Compose | app / db / voicevox のコンテナ管理 |
| 通信 | HTTP / JSON / multipart | エッジ⇔サーバー、独自フレーム（4バイト長+本体）で音声ストリーミング |

## 3. 外部サービス連携

| 連携サービス | 役割 | 備考 |
|---|---|---|
| Google Gemini API（2.5 Flash） | 状況理解・緊急度判定（脳） | 無料枠を活用 |
| LINE Messaging API | 家族へのプッシュ通知 | 緊急・会話ログ・定期通知 |
| Gmail SMTP | 認証コードのメール送信 | アプリパスワード使用 |

## 4. コンテナ構成（docker-compose）
| サービス | イメージ/内容 | ポート |
|---|---|---|
| app | 本体（Flask, `server/main.py`） | 5000 |
| db | MySQL 8.0 | 3306 |
| voicevox | `voicevox/voicevox_engine:cpu-ubuntu20.04-latest` | 50021 |

> エッジ（Raspberry Pi）はコンテナではなく、Pi上で直接 `edge/app.py` を実行（カメラ・マイク・GPIOへ直接アクセスするため）。
