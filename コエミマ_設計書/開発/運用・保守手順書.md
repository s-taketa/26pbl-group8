## 1. 起動・停止

### サーバー
```bash
cd ~/26pbl-group8
docker compose up -d          # 起動
docker compose ps             # 状態確認（app/db/voicevox が Up）
docker compose stop           # 停止（データ保持）
docker compose restart app    # アプリのみ再起動（テンプレ/設定反映時）
```

### エッジ（Pi）
```bash
cd /home/pbl8/edge && bash start.sh    # 起動
# 停止: Ctrl+C（フォアグラウンド時）
```

## 2. 死活監視
- エッジは30秒ごとに `GET /api/heartbeat` を送信。エッジのログに `✅ サーバー接続OK` / `❌ 接続できません` が出る。
- サーバーの稼働確認：`curl http://localhost:5000/api/heartbeat` → `{"status":"ok"}`

---

## 3. ログの確認
```bash
docker compose logs -f app        # アプリログ（認識・通知・エラー）
docker compose logs --tail=50 app # 直近のみ
docker compose logs db            # DB
docker compose logs voicevox      # 音声合成
```
主なログの意味：
| ログ | 意味 |
|---|---|
| `[AI] 解析結果: {...}` | Gemini解析成功 |
| `[ALERT] 緊急検知` | 緊急判定→LINE通知 |
| `[ERROR] 処理中にエラー` | 認識処理の例外（原因を確認） |
| `[WARN] LINE通知は無効` | LINEトークン未設定 |

## 4. バックアップ

### DB
```bash
# バックアップ
docker compose exec db mysqldump -u ai_assistant -pchangeme ai_assistant_db > backup_$(date +%F).sql
# リストア
docker compose exec -T db mysql -u ai_assistant -pchangeme ai_assistant_db < backup_YYYY-MM-DD.sql
```

### 画像
`image-storage` ボリューム（`/app/images`）を定期バックアップ。`docker compose down -v` はボリュームごと消えるため注意。

## 5. トラブル対応早見表
| 症状 | 確認・対処 |
|---|---|
| ログインできない | `docker compose logs app` でDB接続を確認。pymysql未導入なら `--build` |
| 認識で500 | `[ERROR] 処理中にエラー` の内容確認。Geminiキー切れが多い |
| 音声が出ない | エッジで `aplay -D <APLAY_DEVICE> test.wav` が鳴るか |
| 通知が来ない | LINEトークン/宛先ID、`通知送信失敗(ステータス)` を確認 |
| キーワード不反応 | エッジに `keyword_listener.py` 反映、モデル/合言葉を確認 |
| 映像が出ない | `http://<PiのIP>:5002/video` が開くか、`EDGE_URL` を確認 |
