サーバー（Ubuntu）とエッジ（Raspberry Pi 5）で手順が分かれる。

---

## 1. サーバー（Ubuntu / Docker）

### 1.1 前提
- Docker / Docker Compose インストール済み
- リポジトリを配置済み（`~/26pbl-group8`）

### 1.2 `.env` 設定（リポジトリ直下）
```bash
# AI
GOOGLE_GEMINI_API_KEY=（有効なGeminiキー）

# DB（compose と一致させる）
DB_USER=ai_assistant
DB_PASSWORD=changeme
DB_NAME=ai_assistant_db

# VOICEVOX（compose内はサービス名）
VOICEVOX_HOST=voicevox
VOICEVOX_PORT=50021

# セッション（本番は必ずランダム値）
FLASK_SECRET_KEY=（ランダムな長い文字列）

# メール認証コード（Gmailアプリパスワード）
SMTP_USER=xxx@gmail.com
SMTP_PASS=（16桁アプリパスワード）
SMTP_FROM=xxx@gmail.com

# LINE通知
LINE_CHANNEL_ACCESS_TOKEN=（長期チャネルアクセストークン）
LINE_USER_ID=（宛先ユーザーID）

# エッジ映像URL（ダッシュボード埋め込み）
EDGE_URL=http://<PiのIP>:5002

# エッジ⇔サーバーの共有トークン（推奨。エッジ側 edge/app.py にも同じ値を設定する）
EDGE_API_TOKEN=（ランダムな文字列）

# 定期通知の間隔（分）
PERIODIC_NOTIFY_MINUTES=60

# HTTPS化した場合のみ 1（セッションCookieにSecure属性を付与）
FORCE_HTTPS=0
```

### 1.3 ビルド＆起動
```bash
cd ~/26pbl-group8
docker compose up -d --build      # ★依存更新時は必ず --build
docker compose ps                 # app / db / voicevox が Up
docker compose logs -f app        # 「テーブル初期化 完了」「Running on 0.0.0.0:5000」
```

### 1.4 起動確認
```bash
curl http://localhost:5000/api/heartbeat      # {"status":"ok"}
# ブラウザ: http://<サーバーIP>:5000/login → 新規登録してログイン
```

### 1.5 よくある不具合
| 症状 | 原因 | 対処 |
|---|---|---|
| `No module named 'pymysql'` | ビルドキャッシュ | `docker compose build --no-cache app` |
| `Access denied` (DB) | 旧ボリュームの資格情報不一致 | `docker compose down -v` で再初期化 |
| Gemini 401/403 | キー無効・プロジェクト制限 | 有効な個人Gmailの新規プロジェクトキーに差し替え |
| `/health 404` ログ | ヘルスチェックのみ | 動作影響なし（無視可） |

## 2. エッジ（Raspberry Pi 5）

### 2.1 依存インストール
```bash
cd /home/pbl8/edge
source env/bin/activate            # venv
pip install vosk pyaudio opencv-python picamera2 requests flask gpiozero lgpio
# Voskの日本語モデルを model/ に配置（精度重視なら vosk-model-ja-0.22）
```

### 2.2 設定（`edge/app.py`）
| 変数 | 説明 |
|---|---|
| `SERVER_URL` | サーバーのIP:5000 |
| `APLAY_DEVICE` | 出力スピーカー（例 `plughw:2,0`。`aplay -l` で確認） |
| `BUTTON_GPIO` | 物理ボタンのGPIO番号（既定18=BCM18） |
| `EDGE_API_TOKEN` | サーバーの `.env` と同じ値を設定すると、通信とライブ映像がトークンで保護される（推奨） |

### 2.3 起動
```bash
cd /home/pbl8/edge
bash start.sh          # または python3 app.py
```
起動ログに `物理ボタン(GPIO18)を有効化` / `ウェイクワードの監視を開始` が出れば正常。

---

## 3. 停止・クリーンアップ（サーバー）
```bash
docker compose down          # 停止（データ保持）
docker compose down -v       # DBボリュームごと削除（初期化）
```
